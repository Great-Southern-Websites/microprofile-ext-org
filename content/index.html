Extensions

Five extensions, each in its own repository. The name links to the README.

  1. 01

    Config

    Extra Config sources and utilities.

    microprofile-extensions/config-ext
  2. 02

    OpenApi

    Swagger UI for OpenApi.

    microprofile-extensions/openapi-ext
  3. 03

    Health

    Additional reusable health probes and UI.

    microprofile-extensions/health-ext
  4. 04

    JAX-RS

    Some extensions for JAX-RS.

    microprofile-extensions/jaxrs-ext
  5. 05

    REST Client

    Some extensions for REST Client.

    microprofile-extensions/restclient-ext

About the project

Extensions for MicroProfile is a community project. Each extension is a separate repository under the microprofile-extensions organisation on GitHub, with its own README covering what it does and how to add it to a project.
